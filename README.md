# Blue triangle speedrun simulator

Um jogo simples desenvolvido no Construct 3 onde você controla um triângulo azul e precisa chegar até o final da fase, ganhando pontos a cada argola coletada.

🎮 Como Jogar:

Você controla um triangulo azul e tem que chegar até a fase final sem encostar em nenhum dos inimigos
Utilize as setinhas do teclado para se movimentar


🎯 Objetivo:

Chegue até o final da fase sem tocar em nenhum dos inimigos

☁️ Integração com Firebase:

O jogo está conectado com o Firebase, que armazena os dados dos jogadores.

Após o Game Over, será solicitado seu nome.

Aperte "R" para reiniciar

Seu nome e pontuação são enviados e salvos no banco de dados para fins de ranking.

🚀 Tecnologias Utilizadas:

-Construct 3

-Firebase (Autenticação e Banco de Dados Realtime)

📦 Como Jogar:

Entre no link: https://www.construct.net/en/free-online-games/blue-triangle-speedrun-76066/play

utilize as setinhas do teclado

Chegue até o final

Insira seu nome após o game over para registrar sua pontuação.
